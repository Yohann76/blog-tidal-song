# Blog Tidal Song

This is a blog "Tidal Song", with only HTML/CSS technologies. 

# Start project 

```
git clone votre-repo
cd blog-tidal-song
```

```
make logs          # Voir les logs
make backup        # Sauvegarder
make ssl           # Obtenir SSL
make update        # Mettre à jour
make stop          # Stop app
```

```
cp env.example .env
(update .env with your domain)
```

```
make run
```

available here: http://localhost
